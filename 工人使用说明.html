高速公路危害点照片采集
工人使用说明

一、使用流程

1打开表单

  • 用手机浏览器打开 form.html 文件
  • 建议"添加到主屏幕"，以后像APP一样直接点击打开
操作方法：在手机浏览器中点击"菜单" → "添加到主屏幕"，之后桌面会出现一个图标，点击即可打开

2选择路线

  1. 在"选择路线"下拉框中选择当前工作的路线
  2. 如果是新路线，点击"新建线路"按钮，输入路线名称
  3. 设置施工日期（默认今天）
  4. 设置施工路段范围（起始和终止公里桩）

3填写位置信息

  1. 公里桩（必填）：输入里程碑公里数，如 235
  2. 百米数（必填）：输入百米桩编号，如 040
  3. 上下行：选择上行或下行（默认上行）
  4. 车道：选择超车道/行车道/应急车道（默认行车道）
  5. 米数：输入精确米数，如 5.5（默认0）
  6. 备注：如有特殊情况可填写备注

4上传照片

  1. 点击"施工前"按钮，拍照或选择照片上传
  2. 点击"施工中"按钮，上传施工中照片
  3. 点击"施工后"按钮，上传施工后照片
  4. 已上传的按钮变绿色，可以删除重传
  5. 三张照片可以分多次上传，系统会自动记住
照片上传后会自动压缩，不用担心占用太多空间

5提交

  1. 确认信息无误后，点击中间的圆形"提交"按钮
  2. 提交后序号自动+1，可以继续采集下一个点
  3. 如果同一位置有多道裂缝，序号会自动递增

6补充照片

  1. 如果某个点缺照片，点击下方的记录或序号圆点
  2. 进入编辑模式，切换到缺失的阶段上传照片
  3. 点击"保存修改"完成补充

7导出数据

  1. 每天工作结束后，点击底部"导出线路"按钮
  2. 会下载两个文件：CSV表格 + ZIP照片包
  3. 把文件传给管理人员

二、常见问题及解决方法

问题1：照片上传失败

原因：照片太大或浏览器不支持

解决：

  • 系统会自动压缩照片，如果还是失败，试试换一张照片
  • 确保手机浏览器是Chrome或Safari
  • 清除浏览器缓存后重试

问题2：页面打不开或显示异常

原因：浏览器兼容性问题

解决：

  • 使用Chrome或Safari浏览器
  • 清除浏览器缓存
  • 重新打开文件

问题3：数据丢失

原因：清除了浏览器数据或换了手机

重要：数据存在手机浏览器里，清除浏览器数据会丢失！每天必须导出数据备份！

解决：

  • 如果数据丢失，只能重新采集
  • 预防措施：每天工作结束后立即导出数据

问题4：存储空间不足

原因：照片太多，存储空间满了

解决：

  • 页面顶部会显示存储空间使用情况
  • 超过20MB会显示橙色警告
  • 超过40MB会显示红色警告，需要立即导出清空
  • 点击"清空记录"释放空间（先确保已导出数据）

问题5：序号不对

原因：切换了路线但没有正确操作

解决：

  • 切换路线后，序号会自动重置
  • 如果序号不对，检查是否选对了路线
  • 可以在编辑模式中手动修改序号

问题6：照片找不到

原因：导出的照片打包在ZIP文件中

解决：

  • 照片文件名包含位置信息，如 00001_K235_000_横缝_1_前_5.5m.jpg
  • 根据文件名可以对应到表格中的记录
  • 自动编号（00001）与表格行号一一对应

三、每天导出数据的具体步骤

1确认数据完整

  1. 检查所有采集的记录是否都有三张照片
  2. 如果有缺失，先补充照片
  3. 查看页面顶部的存储空间，确认数据量

2导出当前线路

  1. 确认当前选择的是正确的路线
  2. 点击底部"导出线路"按钮
  3. 手机会下载两个文件：
    • 危害点采集记录_路线名称_日期.csv（表格）
    • 危害点照片_路线名称_日期.zip（照片包）

3传输文件到电脑

方法1：微信传输

  1. 打开微信"文件传输助手"
  2. 发送下载的CSV和ZIP文件
  3. 在电脑上接收文件

方法2：数据线传输

  1. 用数据线连接手机和电脑
  2. 在手机文件夹中找到下载的文件
  3. 复制到电脑

方法3：云盘传输

  1. 上传文件到百度网盘/腾讯微云
  2. 在电脑上下载

4在电脑上查看

  1. 用Excel或WPS打开CSV文件
  2. 解压ZIP文件查看照片
  3. 核对数据是否完整

5清空手机数据（可选）

  1. 确认数据已安全传输到电脑
  2. 点击底部"清空记录"按钮
  3. 输入"清空"确认
  4. 释放存储空间，准备第二天的采集

四、注意事项

  1. 每天必须导出数据：数据存在手机浏览器里，不清理会满
  2. 不要清除浏览器缓存：这会丢失所有数据
  3. 不要换手机使用：数据不会同步到新手机
  1. 照片分三次上传没问题：系统会自动合并到同一条记录
  2. 新建路线时注意修改公里桩和百米数：系统会保留上次的位置信息
  3. 提交前检查照片：确保三张照片都上传成功
  4. 序号圆点可以点击：快速跳转到对应记录进行编辑
